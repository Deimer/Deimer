### 🚀 Stack Tecnológico & Especialidades

#### 📱 Mobile Development
* **Android Native (Expertise):** Kotlin, Java, Jetpack Compose, Android SDK, View System (XML/Data Binding), Custom Views, Background Tasks (WorkManager, Services).
* **Multiplatform & Cross-Platform:** Kotlin Multiplatform (KMP), Flutter (Dart), React Native, Swift (iOS Native).
* **Arquitectura & Principios:** Clean Architecture, MVVM, MVI, Modularización (Feature Modules, Dynamic Delivery), SOLID, Design Patterns.
* **Inyección de Dependencias:** Koin, Hilt, Dagger.
* **Programación Asíncrona & Reactiva:** Coroutines, Flow (StateFlow, SharedFlow), RxJava.
* **Persistencia & Red:** Room Database, EncryptedSharedPreferences/DataStore, Retrofit, Ktor, REST APIs, GraphQL, WebSockets.
* **Seguridad & Rendimiento:** Biometría, Almacenamiento Seguro (Keystore), Ofuscación (ProGuard/R8), Optimización de Memoria (LeakCanary, Profiler).
* **Testing & CI/CD:** JUnit, Mockk, Espresso, GitHub Actions, Fastlane.

#### ⚙️ Backend & Bases de Datos
* **Frameworks & Lenguajes:** Laravel (PHP), Python, .NET (C#).
* **Bases de Datos & Cloud:** PostgreSQL, MySQL, SQLite, Firebase (FCM, Firestore, Auth, Crashlytics).
